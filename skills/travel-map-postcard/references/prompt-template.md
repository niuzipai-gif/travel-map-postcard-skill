# Agent invocation template

Use the user's specific constraints when present; this template is the default editorial version.

> 请把这张旅行摄影作品制作成独立杂志 / Travel Zine 风格的地理视觉作品。
>
> 地点：自动识别并核验；我若另行提供地点，把它作为待核对线索。区分画面中的地标、拍摄区域与相机精确位置。不能确定会影响地图的地点时，再问我一个必要问题。
>
> 尽可能完整保留原照片，不重新创作人物、动物、建筑、山体、天空，不改变原有色彩、光影、画幅比例和分辨率。使用独立透明 PNG 图层合成，不重新生成整张照片。
>
> 自动选择真实城市道路、水系、海岸线或山地步道。等高线只有真实高程数据支持时才添加。地图沿天空、海面等负空间充分展开，可自然延伸到画面边缘；15%–25% 作为起点，大天空可扩大，避让主体优先。用原片云层的遮淡、建筑轮廓的遮挡及地图线条的虚实建立前后层次，不做悬浮的椭圆小地图或方形卡片。
>
> 让地图有清楚主次：大标题优先用当地语言/文字，小标题用英语，日本用日文、韩国用韩文，以此类推，避免只有英文。地点标题和照片中的核心地标最清楚，海岸/主路为中层，细街道和外围细节退到背景。使用细线、低饱和度和少量地名；核心地标可用更大的标注、引线及真实轮廓突出。缩到手机宽度仍应看清核心，不把整张地图一起压淡。用小红点标识拍摄区域；没有准确 GPS 或机位证据，就写 approx. area，并在配置记录估计范围，默认不画范围圈。不要伪造坐标、比例尺和旅行路线。
>
> 根据原片负空间的实际色相、明暗和来光方向确定地图微光。重要位置的真实轮廓、岸线或主路更亮一些，外围线条保持细淡，亮线避让标题与注释。默认可使用无色块的纯线稿。需要实景核心时，重点建筑用能辨认建筑本体的实拍标记，不只放周边街区航拍；山体可用真实航拍。只根据标记所在背景调节重点实景层的透明度，保留实拍颜色、核心细节与柔和边缘，地图本身的透明度和层次保持独立。实拍符号锚定真实地标并明确不按比例，航拍按真实地理位置对齐；不改原片来迁就地图。
>
> 保留原片已有质感，地图做轻微印刷感；不加全图滤镜或多余装饰。交付无损成品、透明地图层，以及地点依据和像素验收结果。

Template instructions are for the **agent and compositor**. Do not send the whole original photo to an image generator to satisfy a layer-compositing request. Agent vision, web research, map extraction and layout judgment remain separate from deterministic rendering.
